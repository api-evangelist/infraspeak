# Infraspeak

> Infraspeak is an intelligent facilities and maintenance management platform (CMMS/IWMS/IFM) founded in Porto, Portugal, that connects an entire operation with end-to-end collaboration, complete asset visibility, and intelligent automation. It exposes a public REST API (v3) at api.infraspeak.com, documented on Stoplight, plus an integrations layer ("Infraspeak Hub").

## APIs

- [Infraspeak REST API (v3)](https://api.infraspeak.com/docs): REST API for assets, work orders, failures, preventive maintenance, stock, and suppliers. Base URL https://api.infraspeak.com.

- [API Reference (Stoplight)](https://api.infraspeak.com/docs/infraspeak-api): Interactive REST reference.
